# Workspace

一个只认识两样东西的桌面工作台：**磁盘上的路径**，和**你自己写的字**。

- 文件留在原地，workspace 只记路径，从不读取内容（PDF 交给 Dual PDF，其他交给系统默认程序）。
- 条目是你的笔记，正文就是 Markdown，可随时在「源码 / 渲染」之间切换，公式走 KaTeX。
- 画布是 AFFiNE 那种无限画布：位置是数据，重开还在你摆的地方。一个项目 = 一张画布。
- 环境是**接线端子**：它做哪些事，取决于你把它连到了哪些块；另外可以自己写几条脚本（函数体）。

## 构建

需要 .NET 10 SDK。运行时还需要 WebView2 Runtime（Windows 11 自带，Windows 10 可能要单独装）。

```powershell
dotnet publish .\workspace.csproj -c Release -o "$env:LOCALAPPDATA\workspace\app"
& "$env:LOCALAPPDATA\workspace\app\Workspace.exe"
```

装到别的位置改 `-o` 就行。开发时直接 `dotnet run`，这时读的是源码目录里的 `assets\`。

## 数据在哪

```
%APPDATA%\workspace\index.json               文库、项目列表、设置
%APPDATA%\workspace\projects\<id>.json       一个项目：条目 / 块 / 连线 / 环境 / 任务
%APPDATA%\workspace\projects\<id>.runs.jsonl 运行记录（追加）
%APPDATA%\workspace\workspace.log            日志（出问题时看这里）
```

写入是「先写临时文件再替换」，断电不会留半个坏文件。

## 四种块

| 块 | 它是谁 | 双击 |
|---|---|---|
| 条目 | 你的笔记（Markdown） | 打开右栏编辑器 |
| 文件 / 文件夹 | 盘上某个路径的引用 | 用对应程序打开 |
| 程序 | `.exe` / `.lnk` / `.bat` | 启动它 |
| 网页 | 一个网址 | 用浏览器打开 |
| 文库 | 一批导入的文件/文件夹 | 看收录了什么 |
| 工作环境 | 一串作用项 + 脚本 | 运行它 |

## 子文库

文库检查器里点「拆分子文库」，勾这个文库下的文件夹或文件（勾文件夹 = 整个文件夹进去），取个名字，就在父文库下面多一个子文库。

- 子文库**不出现在左栏「文库」**里，只能在父文库检查器的「子文库」一节找到。
- 它是父库的一个切片，不是复制：存的是勾中的文件夹路径，每次读都重新展开，所以父库后来新增的文件它自动看得到，不需要同步。
- 反过来它不能再往里加东西（只读子集）；要改内容，回父库重新拆一个。
- 删父库会连带删掉它的子文库。

## 环境怎么接

**画一条线到环境，环境里就多一个「作用项」。** 配置存在环境块自己身上（不是存在线上）。

| 连到什么 | 要填什么 | 运行时会做什么 |
|---|---|---|
| 文件 / 文件夹 / 程序 / 网页 | 开不开 + 打开方式 | 开着就打开，关着跳过 |
| 文库 | 选择器（`*.pdf`）或枚举 | 选择器：匹配到的全打开；枚举：只打开你勾的那些 |
| — | 函数体里的脚本 | 按顺序执行你写的命令 |

打开方式留空 = 按扩展名走：`.pdf` → Dual PDF，`.exe/.lnk` → 系统，其余 → 默认程序。

## 操作

| 想做什么 | 怎么做 |
|---|---|
| 新建项目 | 左下「＋ 新建项目」 |
| 删除环境 | 选中环境，检查器最下方「删除这个环境」；或在画布上右键环境块。会连带清掉画布上的环境块和连线 |
| 新建文库 | 左栏「文库 ＋」→ 只填名字；之后「＋ 文件 / ＋ 文件夹」导入 |
| 拆分子文库 | 文库检查器「动作」→「拆分子文库」，勾文件夹或文件，起名 |
| 把东西放上画布 | 从左边**拖到画布上**；或右键画布空白 → 新建文件块 / 文件夹块 / 网页块 |
| 从资源管理器拖文件进来 | 直接拖进窗口 |
| 移动视角 | 滚轮上下、Shift+滚轮左右、空格+拖动或中键拖动平移 |
| 缩放 | 左下 **− 100% ＋**，或 Ctrl+滚轮，或 Ctrl+±；Ctrl+0 回 100% |
| 选中多个 | 空白处拖出选框；Shift/Ctrl 点选 |
| 连线 | 悬停块，从四边的小圆点拖到另一个块上 |
| 复制一块 | 选中后 Ctrl+D |
| 设为紧急 | 条目检查器里点 ⚡，然后选 A / B / C |
| 搜索 | Ctrl+K |

## English-only

一个开关（标题栏 `EN`）、一种态度：条目尽量用英文写。中文不拦你，但会被标出来。

| 层 | 什么时候动 | 你看到什么 | 花 token 吗 |
|---|---|---|---|
| 本地检测 | 每次输入 | 正文里的中文加橙色虚线下划线；左栏条目行一个「中」、项目名后「中 N」= 还有中文的条目数 | 不花 |
| 建议 | 停手约 0.9 秒 | 光标所在段落里的中文 → 一条「自然」+ 一条「简洁」英文，点一下只替换那一段 | 约 350 / 次 |
| 检查与优化 | 条目检查器里的按钮 | 英文条目：语法错（错）+ 改进（改）；整段中文的条目：直接给英文改写（译），逐条「应用」或「全部应用」 | 约 500–1500 / 次 |

- 替换走 textarea 原生 `setRangeText`，撤销还在；模型只提议，不会自己写盘。
- 关掉 `EN` = 关掉自动建议和全部标色；「检查与优化」按钮还在，手动能用。
- 同一段文字 + 同样上下文，十分钟内再问不花钱（内存缓存）。
- 超过 8000 字符的条目拒绝检查，先分节。
- 一条中文 → 两条英文时，如果模型给了重复的两条，会再要一次不同说法。

### 模型

设置 → English：

| 项 | 默认 | 说明 |
|---|---|---|
| 服务地址 | `https://api.deepseek.com` | 任何 OpenAI 兼容端点：本地 Ollama `http://127.0.0.1:11434`、LM Studio 都行 |
| 模型 | `deepseek-chat` | 端点有什么填什么 |
| API Key | — | 只存本机 `%APPDATA%\workspace\secret.bin`，Windows DPAPI 按当前账户加密；**不写进 index.json** |
| 停手多久后给建议 | 900 ms | 300–5000 |
| 自动建议 | 开 | 关掉就只在点按钮时问模型 |

「测试连接」会先保存设置，再发一个 16 token 的探针请求。累计 token 在设置里看，可清零。

`%APPDATA%\workspace\secret.bin` 就是那把 key（加密后的）。删掉它等于删 key。

## 紧急任务

只有三档：**A 最急、B 一般、C 可缓**。没有计时、没有死线、没有提醒。左栏和账本都按 A→B→C 排序，点一下就是完成。

## 已知粗糙的地方

- 语义缩放在 40% 以下会隐藏正文，切换那一瞬间比较生硬。
- 卡片底部的路径在窄卡片上会溢出。
- 环境里的脚本会真的执行命令，第一次拿只读命令试。
- 「枚举」模式里换了一批文件后，勾选记录按路径保存，路径变了就失效。
- English-only 一次只检查当前打开的条目，还没有「扫全项目」。

## 改前端

`assets\` 里的 HTML/CSS/JS 不用编译，但**发布版加载的是安装目录里的 `assets`**，只改源码不生效：

```powershell
robocopy .\assets "$env:LOCALAPPDATA\workspace\app\assets" /E
```

改完重开窗口。（从 `bin\Debug` / `bin\Release` 直接跑 exe 时例外，那时 `MainWindow.AssetsDir()` 会向上三级找到源码 `assets\`。）

## 结构

```
App.xaml(.cs)            入口、单实例（第二次启动会把已有窗口叫到前台）
MainWindow.xaml(.cs)     窗口 + WebView2 宿主 + 原生拖放 + 最小尺寸 + 自检(--diag / --probe 脚本)
src/Model.cs             模型：条目 / 块 / 连线 / 环境(EnvFunc) / 任务
src/Store.cs             JSON 落盘、原子写、运行记录
src/Openers.cs           外部程序适配器（Dual PDF 走它的启动器 + DP_OPEN）
src/EnvRunner.cs         环境 → 具体步骤：连线展开、选择器匹配、脚本执行
src/Bridge.cs            页面 ↔ 宿主 通道；文库变化监听；ai.* 转发
src/Ai.cs                模型通道：OpenAI 兼容请求、DPAPI 存 key、三段提示词
assets/js/canvas.js      画布引擎：块、边、缩放、框选、复制、连线即作用项
assets/js/app.js         侧栏 / 检查器 / 账本 / 环境 / 子文库 / 任务 / 搜索 / 拖放
assets/js/english.js     中文检测、建议条、检查卡（English-only）
assets/js/md.js          Markdown 渲染（含 $...$ 公式）
tools/seed-demo.js       生成演示项目（可删）
```
